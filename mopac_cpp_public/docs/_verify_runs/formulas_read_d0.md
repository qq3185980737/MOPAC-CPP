## 0.1  阅读方法

每一模式按“输入 → 公式 → 逐步迭代 → 输出 → 收敛判据 → 源码”组织：先看输入/输出确认适用范围，再看公式与逐条迭代步骤，最后对照判据和源码。公式中的物理量都可在上面的符号表查到含义、单位与出现章节；同一符号在不同章节含义不同时，由 0.2 节的重载约定和该节首句说明区分。

# 2  0SCF 与 1SCF

## 19.4  验证中发现并处理的问题

验证过程同时检查了对应模式的真实输出，发现并处理了以下问题：

1)  force() 的 xyzint 包装曾把 1-based 指针 (&v[1]) 传给 0-based 的 xyzint，导致 FORCE 的几何被破坏（H 原子坐标错误、SCF 失败）。已改为传 data()，修复后 FORCE 的能量与梯度与官方一致（ΔHf=-57.791035 kcal/mol，gnorm=2.79511）；

2)  fmat() 仍是占位函数（只把 nreal 置零），因此 FORCE 的力常数矩阵为零、频率/ZPE 输出为零。这是尚未完成的功能分支，已在 TRANSLATION_GAPS 记录；

3)  STATIC 有限场模式在 C++ 下出现 SCF 不收敛（官方正常），记录为待修复分支；

4)  α 打印末位差（9.67479 vs 9.67480）来自打印精度与跨二进制 ULP 差异，不违反 α_iso=mean(diag) 的公式关系（C++ 内部一致）。

结论：上述公式在代数关系、量纲/单位、迭代不变量和程序输出一致性上均通过验证；未发现公式错误。FORCE 频率与 STATIC 属功能缺口，不是公式错误。

迭代 1：P₀=0 → F₀ = H = [[−10,−2],[−2,−9]]。

## D.3  覆盖结论（是否足够）

1)  s/p 元素 + 6 种方法：水、甲烷、氨、CO、乙烯、硅烷共 35 组，HOF/E_elec/E_nuc 与官方到打印精度完全一致；

3)  不支持组合与官方行为相同（参数缺失），不是实现差异；

4)  因此“公式 + 参数表 + 积分/SCF 实现”的证据链在 s/p 元素、6 种方法、以及 Fe（d 轨道）上已闭合，可作为“理论上可验证”的最低充分证据。

## D.4  尚缺的验证（不是公式错误，是覆盖面）

1)  元素覆盖：镧系/锕系、部分过渡金属、Sparkles 参数未逐一测试；

2)  方法扩展：PM7-TS 输出格式不同（过渡态专用），未纳入本矩阵；

## D.5  如何扩展测试到其他元素/方法

1)  在 MOPAC_parameters.xlsx 中确认该方法是否有目标元素的参数（方法对照表）；

2)  写 deck：<方法> 1SCF + 几何，分别用 C++ 版和官方运行；

3)  比较 E_elec、E_nuc、ΔHf（容差 ±1e−5 kcal/mol 或打印精度）；

## E.5  什么算“全部验证”，以及如何执行

本文档把“全部验证”定义为：对每一分支/模式、每一种支持的方法与元素，用同一输入分别运行 C++ 与官方程序，逐项比较该分支的输出（能量、几何、频率、张量、轨迹等），差异不超过该输出的打印/数值容差。这是可执行的有限清单，不是对所有可能输入的数学证明。

3)  双程序运行，脚本解析输出并生成差异表（参考附录 D 的做法）；

4)  对差异项判断：参数缺失/未实现/数值容差/真正公式错误；

5)  把通过的格子标绿、未通过的标黄并记录原因；全部标绿后即为“全部验证”。

## K.1  判定标准：五要素与四级可复算性

可独立复算需要同时具备五要素：①输入条件（关键字 + 几何 + 电荷/自旋 + 方法）；②完整公式/算法（含迭代、收敛判据）；③参数（数值或可查表来源）；④中间参考值（可逐步对照的 H/W/F/P/ε/E_elec/E_nuc 等）；⑤最终参考值 + 容差（用于判定“合格”）。缺任一要素，读者只能做局部复算。

## K.3  当前文档不满足“读者可复算”的关键缺口

参考中间值覆盖不足：只有 H₂ 全链（A.3/A.5）、§20 手算案例和 I.6–I.11 修复记录给出中间量；其余分支没有可逐步对照的 H/W/F/P/ε/E_elec/E_nuc 等数据，读者只能对最终打印值，无法定位实现错在哪一步。

积分公式不完整：附录 F 只给出 s-s 重叠的闭式，s/p/d 重叠、单电子、双电子与 γ/ecore/reppd 多为形式或“见源码”，读者自写程序需先移植这些模块。

输入条件不完整：每章有“输入：关键字”，但除 H₂（A.1）、37 组矩阵（D.1）与手算案例外，没有给出可复制的 deck（关键字+几何+电荷/自旋）。

参数覆盖不全：MOPAC_parameters.xlsx/csv 提供方法与元素主参数，但 COSMO 半径/方向、色散与氢键经验参数、激发态与 PM7-TS 专属设置、MOZYME 阈值等未在文档/参数表中完整给出。

收敛与默认常量不全：scfcrt、GNORM/DMAX/DDMAX、trust radius 初值、SCF 阻尼/DIIS 等默认值未集中列表，读者难以复现“与程序相同”的迭代路径。

参考输出与容差只覆盖部分分支：D.2/E.3/V 表给出若干最终值；TS/路径/网格/DRC/MD/周期/分析输出/PMEP/PKA/RAPID 等没有参考输出，无法判定“合格”。

MOZYME/COSMO 系缺失公式层：MOZYME 仅一句说明；linear_cosmo/MOZYME+COSMO 只有 2026-10-26 的最终数值（J.4），没有公式与中间量，读者无法独立复算。

文档自述与内容不一致：开头称“参考中间值集中在一处”，实际只有 H₂ 与手算案例满足；本附录 K 作为如实声明与补齐清单。

## K.4  达到“读者可独立复算”的补齐方案

统一模板：为每个分支补一张“复算检查点表”，列：deck（关键字+几何+电荷/自旋）、公式章节、参数来源、程序中间量（H/W/F/P/ε/E_elec/E_nuc/分支特定量）、最终参考值、容差、通过判据。K.6 给出水 PM7 1SCF 的示例。

L2/L3 分支：补最小 deck + 参考中间量 dump（可用 C++/官方双程序输出，见 docs/_verify_runs/），并把公式补全或明确引用 COMPUTATION_FORMULAS.md 的对应小节。

L4 分支：先补“参考算例”（双程序 deck + 输出），再补公式与中间量；顺序按 J.5 的 B/C 类清单。

积分与参数：把附录 F 的 s/p/d 积分闭式补全（或逐式给出可编程伪代码）；把 COSMO 半径/方向、色散/氢键、PM7-TS、MOZYME 阈值等参数补入 MOPAC_parameters 表或新参数附录。

默认常量：新增“默认值与收敛常量”表（scfcrt、GNORM、DMAX、trust radius、DIIS/SHIFT、POLAR 的 ATOL/BTOL 等）。

MOZYME/COSMO 系：补 linear_cosmo 的 B 矩阵/多极/CG 求解公式与中间量（q_sc、Φ、precond 等），并把 J.4 的最终值升级为可复算的检查点表。

执行入口：以 docs/_verify_runs 的 cpp/ref 输出作为参考中间值来源，脚本化生成每分支检查点表，避免手工维护。

## K.5  结论

按“读者依据文档独立手算/编程复算并判定合格”这一目的，当前文档只对以下内容达到要求：附录 A/B/F 的 H₂/PM7 全链（编程复算，含中间值）、§20 的十个手算案例（L1）、附录 D 的 37 组 1SCF 最终值对照（L2 最终值层面）、以及部分分支的最终值抽查（E.3/I.6–I.11）。对其余多数分支，读者只能读到公式框架与状态，缺少可对照的中间量、完整 deck、完整参数或参考输出，无法独立算到程序结果，也无法判定合格。补齐清单见 K.3/K.4；完成后再按 J.5 的分支清单逐项升级为“已验证（可复算）”。

## K.8.5  使用说明与已知偏差

用法：先按 K.6/K.7 准备 deck 与公式，实现 SCF/优化/频率/分析；从程序输出读取本表“官方参考值”，按“判定”列的容差对照。

能量类（K.8.1）以打印精度（5 位小数）为准；恒等式 TOTAL=E_elec+E_nuc 残差应 <1×10⁻¹² eV（V1）。

优化器（K.8.2）：能量与 ΔHf 对到打印精度；C++ 的迭代轨迹/终止点与官方有差异（EF 第 2 轮 1.726 vs 1.741；FLEPO/DFP/L-BFGS 终止点不同），这是已知的优化器数值差异，不影响末端能量。

FORCE/THERMO（K.8.3）：ZPE/频率/熵/焓/Cp 有 10⁻³~10⁻¹ 级差异（频率来源不同，见 I.11）；C++ 的频率打印顺序/标签仍有问题，ZPE 值可对照。

分析输出（K.8.4）：MULLIK/ENPART 一致；LOCAL/BONDS/ESP/PMEP 的 C++ 打印尚未实现（不影响能量），IRC/DRC 有轴序/轨迹差异（见 I.10）。

补充方式：每个分支若要升级为 L2/L3 完整检查点，还需补“程序中间量 dump”（H/W/F/P/ε/E_elec/E_nuc），可在官方输出中读取 EIGENVALUES/电荷/布居，或用调试输出（见 F.7）。

## L.0  使用说明与容差约定

逐分支复算步骤：①取 L 节给出的 deck（或按其改方法关键字/几何）→ ②按“完整公式链”列出的章节实现公式与算法 → ③按“参数”列出的表取参数 → ④自行算出“中间参考值”并与官方值比对 → ⑤算出“最终参考值”并与官方值、C++ 值比对，落入容差即判定合格。

容差约定（沿用 K.8.5）：官方打印精度为 ΔHf 5 位小数（kcal/mol）、能量 5 位小数（eV）、特征值 5 位小数、电荷 6 位小数。判定“一致”的分支容差取 ±5×10⁻⁵（打印精度级）；判定“部分”的分支按该分支实测最大偏差给出容差，ΔHf 与 TOTAL 仍按打印精度。恒等式 TOTAL = E_elec + E_nuc 的残差 ≤1×10⁻⁹ eV。

C++ 对照状态含义：一致＝所有打印量逐位相同；部分＝主值（ΔHf/TOTAL）一致但存在分解量/中间量/打印缺失差异（表内给出具体差异）；未输出＝C++ 未打印该量（无对照）；待补＝存档只有单侧输出或官方不识别关键字（无可比基准）。

与附录 I/K 状态不一致之处的处理：以 _verify_runs 存档实测为准。凡本附录判定与附录 I（未完成分支审计）、附录 K（可复算性评估）或 TRANSLATION_GAPS.md 的记录不一致时，以本附录实测数值与状态为准，并在 L.31 集中修订说明。
